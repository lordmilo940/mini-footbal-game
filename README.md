# Mini Football Game ⚽

A tiny 1-vs-1 football game made with HTML5 Canvas. ARG (you) vs BRA (AI). 60 seconds. Score more goals!

**Play:** open `index.html` in your browser (or visit the GitHub Pages link once it's enabled).

**Controls:** `W A S D` or the arrow keys to move. Run into the ball to kick it.

## Files
- `index.html` — the whole game (HTML + CSS + JavaScript in one file)
